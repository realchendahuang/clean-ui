## 🎯 设立宗旨

很多独立产品功能很强，但第一眼就被劝退，往往是因为缺乏审美克制感：元素拥挤、五颜六色、死板的大厂公文布局。

**克制设计（Clean UI）** 为独立开发者提供极简而优雅的产品审美落地手册：
- **留白与呼吸感**：排版层级、行高与字阶的黄金比例；
- **色彩克制**：黑白灰为主调，全站至多一种功能性强调色；
- **即拷即用代码片段**：Tailwind CSS 调色板、Linear 级细腻边框、原生微动效与骨架屏。

---

## 📐 设计原则与组件

- **Checklist**：上线前自查清单（排版、间距、对比度、手机端适配）
- **Palette**：暗色与亮色极简灰阶配方
- **Components**：无多余修饰的按钮、输入框、卡片与侧边栏代码
